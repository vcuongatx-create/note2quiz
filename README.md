# 📚 Note2Quiz

Biến tài liệu thành bài kiểm tra bằng AI. Upload PDF/ảnh/Word → nhận quiz có đáp án + phân tích điểm yếu.

## ✨ Tính năng
- Upload PDF, ảnh, DOCX, TXT
- Dán văn bản hoặc nhập chủ đề muốn tra
- AI tạo trắc nghiệm + đáp án + giải thích
- Check đáp án → chấm điểm + phân tích chủ đề yếu
- Chat tra kiến thức tích hợp

## 🚀 Cách dùng
1. Mở web
2. Vào tab **⚙️ API** → dán Gemini API key (lấy free tại https://aistudio.google.com/app/apikey)
3. Vào tab **Tạo đề** → upload file hoặc nhập chủ đề
4. Chuyển sang **Làm bài** → check đáp án
